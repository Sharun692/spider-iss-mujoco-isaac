# Sources and export provenance

This repository packages the October 2026 MuJoCo/Isaac ISS walking demonstration for Sharun Arumugam's supervisor review. It intentionally excludes the separate later `iss_modular_assembly` project.

## Research model

Robot dimensions, masses/inertias, gait, compliant attachments and the 16-mode truss coefficients were copied from the user's existing `spider_mujoco_only` research project into the ISS experiment. These are assumed research values, not newly measured hardware data. Both copies of `parameters.json` and `geometry.json` are retained.

The full MuJoCo movie uses the prior standalone 120 s trajectory; the ISS project also independently ran a 36 s trajectory. The Isaac movie uses the independently integrated 120 s GPU PhysX trajectory. The supplied NPZ and JSON records preserve this distinction.

## Upstream code and assets

The surrounding original ISS visualization project is [dara-miao/canadarm-capture](https://github.com/dara-miao/canadarm-capture). Its MIT licence is retained in `outputs/canadarm-capture/LICENSE`. That licence should not be read as automatically relicensing all of the user's separately supplied research code or NASA/CSA assets. No additional repository-wide open-source licence is assigned in this export.

The ISS source is NASA 3D Resources, International Space Station (ISS) (B):

https://github.com/nasa/NASA-3D-Resources/tree/master/3D%20Models/International%20Space%20Station%20(ISS)%20(B)

The processed station mesh data required by these two videos are included in STL (MuJoCo) and vertex/face NPZ (Isaac) form. The original fetch/conversion script is retained as a provenance aid; it also references other assets from the broader Canadarm project that are not used by the spider movie.

Earth imagery is credited to NASA Goddard Space Flight Center, Reto Stöckli and Robert Simmon:

- Land/ocean/ice texture: https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57730/land_ocean_ice_8192.png
- Cloud mosaic: https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57747/cloud_combined_2048.jpg

The Isaac composite uses those images with cloud alpha scaled by 0.85, corresponding to the MuJoCo background implementation. The NASA source imagery and composite are included. Source terms/credits remain applicable; no NASA or CSA endorsement is implied. The broader project's CSA terms link is https://www.asc-csa.gc.ca/eng/terms.asp .

## Export changes versus the original workspace

`original_file_manifest.json` contains SHA-256 hashes and byte sizes of the original selected files before packaging edits. The research workspace was not modified by this export.

Three selected files received portability-only changes in the export: the optional `--preview-source` branch in each MuJoCo truss renderer now reads the packaged full trajectory instead of a workstation-specific home path; the Isaac launcher defaults to `$HOME/simulators/isaac` instead of a particular user's absolute path. Other original selected files remain byte-identical unless explicitly reported by `export_checks.json`.

New files added for this repository include the root README, methods/reproduction/data-format/provenance documents, a requirements list, `.gitignore`, and the reconstructed bridge preparation and importer entry points. The bridge reconstruction was checked structurally against the archived XML, ignoring formatting whitespace. The importer uses the original `work/isaac/import_probe.py` configuration.

Dependencies, virtual environments, binary Isaac installation files, caches, auth files and credentials are excluded. Existing diagnostic JSON files include successful and rejected configurations; auxiliary trajectories for every exploratory configuration are not all packaged. The corrected full-rate pilot and full final trajectories are packaged. Generated static visual USD with workstation-specific texture paths is regenerated by the render script rather than redistributed.

Archived README files describe their historical local context and may mention paths or results outside this curated export. The root README and `REPRODUCE.md` are the entry points for running this repository.
